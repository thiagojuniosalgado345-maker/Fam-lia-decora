O que esta versão ainda não faz

Os pedidos do cliente são enviados diretamente para o WhatsApp informado no site; eles não são gravados num painel central. Para a equipe administrar pedidos, estoque, disponibilidade por item e reservas de diferentes clientes/dispositivos, será necessário configurar uma base de dados (por exemplo, Supabase), autenticação e regras de acesso.
