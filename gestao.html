Como a disponibilidade é calculada

Para cada data, o sistema soma as quantidades reservadas nas festas não canceladas e as quantidades bloqueadas manualmente. Uma nova festa só é salva quando a quantidade pedida não ultrapassa o estoque cadastrado. Festas diferentes no mesmo dia aparecem separadamente no calendário. Esta lógica ainda funciona somente neste navegador; a versão de produção precisará de banco de dados e login para impedir conflitos entre pessoas usando aparelhos diferentes.
